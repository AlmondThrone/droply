# Droply — Video & Media Downloader for Telegram

**Droply** is a Telegram bot for downloading supported videos, audio and images and handling everyday PDF and ZIP tasks directly inside Telegram.

🌐 **Website:** https://almondthrone.github.io/droply/  
🤖 **Telegram:** https://t.me/DroplyFileBot

## What Droply does

- 🎥 **Video downloader** — download supported online videos through Telegram
- 🎵 **Audio & MP3** — extract audio and convert supported media to MP3
- 🖼️ **Image downloads** — download supported images directly in Telegram
- 📄 **PDF tools** — convert, compress, merge, split, rotate and manage supported PDFs
- 🗜️ **ZIP & file tools** — compress and extract supported files
- ⚡ **Simple workflow** — send a supported link or file and receive the result in Telegram

## Free and Pro

## How to use Droply

1. Open **@DroplyFileBot** in Telegram.
2. Send a supported video, audio or image URL, or upload a supported file.
3. Choose an available action.
4. Receive the processed result directly in Telegram.

## Privacy

The public Droply service does not use browser cookies or access a user's PC files, screen, clipboard or personal cloud area. Supported jobs are processed using temporary files.
